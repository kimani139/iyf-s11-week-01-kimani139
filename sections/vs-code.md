# VS Code — Draft by kimani139

Visual Studio Code (VS Code) is a lightweight, extensible code editor ideal for students. This draft expands the VS Code section with practical tips, recommended extensions, and a short example workflow.

## Practical Tips
- Use the Command Palette (Ctrl/Cmd+Shift+P) to quickly run commands.
- Install and enable Auto Save while editing assignments: File → Auto Save.
- Use workspaces to keep project-specific settings and extensions.

## Recommended Extensions
- Python (ms-python.python) — Linting, debugging, and IntelliSense for Python.
- ESLint (dbaeumer.vscode-eslint) — JavaScript/TypeScript linting.
- Prettier (esbenp.prettier-vscode) — Opinionated code formatter.
- Live Server (ritwickdey.LiveServer) — Preview HTML projects locally.
- GitLens (eamodio.gitlens) — Enhanced Git history and blame view.

## Example: Run a Python Script
1. Open terminal: View → Terminal (or Ctrl+`).
2. Create virtual environment: `python -m venv .venv` then activate it.
3. Install requirements: `pip install -r requirements.txt`.
4. Run: `python main.py` or use the Run and Debug view to add a launch configuration.
